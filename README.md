# stable-challenge-time-series-test

see https://github.com/galilai-group/stable-challenge-time-series-test/blob/main/CHALLENGE.md 

The website is published from `docs/`. Scores are generated by the administrator's evaluator. Model files remain private; participant emails appear only when anonymity is disabled.

## Development

```bash
uv sync
uv run test_submission.py example_submission/model.onnx
uv run evaluate.py example_submission/model.onnx /abs/path/to/eval_data   # needs a GPU and the private eval data
```

- `evaluate.py MODEL DATA` is the evaluator. `DATA` is the unzipped private `eval_data.zip` (held by the
  organizers); everything that identifies a task (its data, labels, split, anchors and weight) lives there, not in
  the code.
- `test_submission.py MODEL.onnx` is the participant-facing check (see [CHALLENGE.md](CHALLENGE.md#validate-submission)).
- `example_train.py` trains and exports `example_submission/model.onnx`; `corpus_loader.py` reads the training corpus.
